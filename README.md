# Heart of Scales

A dragon taming mod for Minecraft.

## Branches and versions

| Branch | Target |
|---|---|
| `master` | Minecraft 1.20.1, Forge |
| `1.21.1` | Minecraft 1.21.1, NeoForge |

Features land on `master` first, then are cherry-picked to `1.21.1`. `PORTING.md` lists what differs between the two targets.

Versions are `<feature>+<minecraft>`, for example `0.0.1+1.20.1` and `0.0.1+1.21.1`. The same feature number means the same feature set. `CHANGELOG.md` on each branch lists what that branch's versions contain.
